# Nesse repositório estão os códigos desenvolvidos em java, versão 25. 

Na pasta application temos os códigos main, que importam a classe e executam uma determinada função e na pasta entities temos as classes criadas para cada exercício.

Por enquanto, dia 29/09/2026, foi feito a criação de classes, atributos, construtor, métodos e instanciação no arquivo principal.

Dia 03/10/2026 foi adicionado dois arquivos, um contendo a classe e outro o programa principal, que utiliza os conceitos anteriores de POO, com uma melhor utilização do encapsulamento e método get, além da utilização de um ArrayList para guardar todos os objetos criados nesse exercício.

Dia 11/10/2026 foi adicionado um exercício utilizando técnicas como composição e enum, onde pegamos dados de um cliente e depois a quantidade de itens que ele pediu, em seguida pegamos os dados desses itens pedidos e guardamos em uma lista, ao final exibimos todas as informações.

# Funções de Data em Java

No arquivo demontracaoDataeHora.java temos as principais funções da API `java.time`, utilizando `LocalDate`.

## Conteúdos

* Criação de datas
* Consulta de dia, mês e ano
* Cálculo de idade com `Period`
* Adição e subtração de dias, semanas, meses e anos
* Comparação entre datas
* Verificação de ano bissexto
* Quantidade de dias do mês e do ano
* Primeiro e último dia do mês
