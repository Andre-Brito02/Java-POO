# Nesse repositório estão os códigos desenvolvidos em java, versão 25.

Cada pasta contém a resolução de um exercício, proposto pelo professor Nélio Alves, no curso Java COMPLETO Programação Orientada a Objetos + Projetos.

A ideia desse repositório é documentar a minha evolução da linguagem Java, principalmente na área da programação orientada ao objeto.

Atualmente estou vendo sobre Herança, sobreposição e uma breve introdução sobre polimorfismo.

# Conteúdo visto:
- Classes
- Atributos
- Métodos
- Encapsulamento
- Construtor
- Métodos get e set
- Sobrecarga
- Enum
- Composição
- List e ArrayList
- Herança
- Sobreposição
- LocalDate, LocalDateTime, DateTimeFormatter, Instant
